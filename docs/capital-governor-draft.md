## 1. State Machine

```
OBSERVE -> PILOT -> SCALE -> [DE-RISK | HALT | HARVEST]
                                  |         |
                                  v         v
                               SCALE    POST-MORTEM -> OBSERVE
```

### OBSERVE (current state)

Virtual-only paper trading. No real capital at risk. Continues until
Phase 6 graduation PASS (30 trading days, pre-registered discriminator).

Exit condition: graduation PASS -> PILOT.

### PILOT

First real capital deployment via Phase 8a semi-auto bridge.

| Parameter | PROPOSED | Rationale |
|-----------|----------|-----------|
| Initial capital | 50K-100K CNY | USER DECISION. Enough for meaningful test, small enough that a total loss is a tuition fee, not a crisis. |
| Duration | 30 trading days minimum | Same observation window as Phase 6; validates the bridge, not the model (model already validated virtually). |
| Success criteria | paper-vs-real drift < 2% of daily turnover for 30 consecutive days (ADR-0001). |

Exit condition: PILOT success -> SCALE.
Fail condition: ANY of DE-RISK triggers -> DE-RISK.

### SCALE

Incremental capital addition on demonstrated performance.

| Parameter | PROPOSED | Rationale |
|-----------|----------|-----------|
| Step size | +50K CNY per quarter | Conservative; keeps total deployment under control. |
| Conditions (ALL must hold) | (1) Live-paper drift in band (<2% sustained); (2) Rolling 6-month absolute return > 0; (3) Peak drawdown from high-water mark < 10%. |
| Maximum | No hard cap proposed; USER DECISION at each step. |

The SCALE ladder also unlocks board permissions:
- At 500K + 24-month clock: apply for STAR/ChiNext/BSE access -> IPO
  harvest Stage 1 (5.9% -> 7%+ EV).

### DE-RISK

Automatic risk reduction. Triggered by ANY of:

| Trigger | PROPOSED Threshold | Action |
|---------|-------------------|--------|
| NAV drawdown from peak | -10% (ADR-0001) | Cut equity exposure to 50% of current; raise cash sleeve to 50%. |
| Drift sustained | >2% for 5 consecutive trading days | Same as above. |
| K=3 discriminator fires | Pre-registered (Phase 6 graduation doc) | Same as above. |

Recovery: maintain DE-RISK state for minimum 10 trading days, then
re-evaluate. If triggers clear, return to SCALE (at reduced capital --
the cut capital is NOT automatically re-deployed).

### HALT

Emergency full stop. Triggered by ANY of:

| Trigger | PROPOSED Threshold | Action |
|---------|-------------------|--------|
| NAV drawdown from peak | -15% | Flatten ALL equity to cash. No new orders. |
| Data integrity incident | Any (pipeline failure >3 consecutive days, ledger corruption, deploy drift detected) | Same as above. |

Recovery: post-mortem document required before restart. Post-mortem
answers: (1) root cause identified? (2) fix deployed and tested?
(3) user approves restart? If yes to all -> return to OBSERVE (restart
the validation cycle, not PILOT).

### HARVEST

Mechanical profit extraction. Runs quarterly, overlaid on any active state.

| Parameter | PROPOSED | Rationale |
|-----------|----------|-----------|
| Threshold | Realized YTD profit > 8K CNY | ~1 year of platform costs (5K) + margin. |
| Action | Move threshold amount out of trading capital (real transfer or ledger bucket). |
| Constraint | Never replenish after losses in same year (no martingale). |
| FX path | Bank FX conversion within annual facilitation quota (50K USD/person/yr, MASTER section 1b). At current scale ($1-3K/yr), not binding. |

This closes the "feed fable" loop: platform costs covered by platform profits.

## 2. Cash Buffer for IPO Payments

When IPO subscriptions are active, maintain liquid cash >= maximum
single-lot cost among currently subscribed IPOs. This prevents the
win-payment default risk (R-IPO-3: 3 defaults -> 6-month subscription ban).

PROPOSED: floor = max(issue_price * shares_per_lot) across active
subscriptions, typically 5K-50K CNY depending on issue price.

## 3. Annual Accountant Export (LEAK-2)

Required regardless of strategy (FBAR + Form 8938 thresholds already
exceeded at current account value ~42K USD equivalent).

Export spec (annual, December):
```
1. Realized gains by lot: symbol, buy_date, sell_date, buy_price, 
   sell_price, qty, gain_loss_cny, holding_period_days
2. Dividends received: symbol, date, amount_cny (if any; pipeline 
   currently ignores dividends -- add when first dividend received)
3. Account balances: year-end total_nav, cash, equity_value in CNY
4. FX conversion records: date, cny_amount, usd_amount, rate 
   (manual entry from bank statements)
```

Format: CSV files in `exports/YYYY/` directory, generated by a CLI
command `paper export --year 2026`. No automated tax filing; this is
input for the accountant.

## 4. Signals Are Self-Referential

All governor signals reference OWN data:
- NAV: from paper.db nav table
- Drift: from reconciliation table (Phase 8a)
- K=3 discriminator: from existing verdict comparison
- Drawdown: computed from own NAV series

No market forecasting. No regime signals (twice refuted). No external
indicators. The governor is a mechanical safety net, not a trading signal.
